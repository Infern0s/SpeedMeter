# SpeedMeter

Приложения для Windows и Android измеряют задержку HTTP, загрузку и отдачу до сервера LibreSpeed Clouvider во Франкфурте. За запуск передаётся около 29 МБ полезных данных. Результат зависит от маршрута до сервера, фонового трафика и размера передаваемых данных.

- Windows: `windows/SpeedMeter.cs`, .NET Framework 4.5 или новее.
- Android: `android/src/main`, Android 6.0 или новее. Скрипт сборки рассчитан на JDK 17 и Android SDK Platform / Build Tools 35.

Разработано отдельно от кода, извлечённого из исходного APK.
